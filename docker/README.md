# Docker exercise

The qualification includes a separate Docker exercise based on Docker's `getting-started-app` Todo application. It is separate from the Flask coding-agent task.

## What this folder is for

Keep the Docker exercise notes and, once the actual Todo starter project is available, its Dockerfile and any supporting files required by the qualification.

## Current status

No Todo application source has been added here, and no Dockerfile has been built or tested. A Dockerfile must be written against the actual starter project's files and runtime instructions rather than guessed from a generic example.

## Validation to record

After the starter project is available:

1. Inspect its package files and start command.
2. Write the Dockerfile for that exact application.
3. Build the image.
4. Run the container and confirm the app is reachable.
5. Record the exact build and run commands and their results.
6. Include the required configuration and hidden `.opencode` files in the submission ZIP if the qualification instructions require them.

Do not mark the Docker exercise complete until the image has been built and the application has been tested.
